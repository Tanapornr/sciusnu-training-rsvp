# อีเมลยืนยันการลงทะเบียนทันที

หลังบันทึกทะเบียนสำเร็จ Apps Script ส่งอีเมลส่วนตัวถึงผู้ลงทะเบียน 1 คนต่อข้อความ ไม่มี CC/BCC และไม่แสดงรายชื่อผู้อื่น

1. วาง Code.gs รุ่น 1.3.1 ในโครงการเดิม โดยคง Script Properties เดิม
2. เรียก setupConfirmationEmails หนึ่งครั้ง ฟังก์ชันนี้เพิ่มคอลัมน์ O–R และสร้างทริกเกอร์สำรองทุก 5 นาที โดยไม่ส่งอีเมลระหว่างตั้งค่า ไม่ส่งย้อนหลังให้ทะเบียนเก่า
3. อัปเดตการทำให้ใช้งานได้เดิมด้วยเวอร์ชันใหม่ URL /exec คงเดิม จึงใช้ APPS_SCRIPT_URL เดิมใน Vercel ได้
4. อัปเดตเว็บไซต์จาก GitHub หลังทดสอบแล้ว

สถานะ O–R: SENT คือผู้ให้บริการรับข้อความแล้ว, PENDING คือรอโควตาหรือรอคิว, SENDING/ERROR ต้องตรวจประวัติการส่งก่อนส่งใหม่ ระบบไม่ส่งซ้ำอัตโนมัติในกรณีผลส่งไม่แน่นอน การขัดข้องของอีเมลไม่ลบทะเบียน และการกดซ้ำไม่ส่งข้อความเพิ่ม

โควตาอีเมลขึ้นกับบัญชี Google ที่รัน Apps Script หากโควตาหมด รายการใหม่ยังบันทึกได้และรอทริกเกอร์ส่งเมื่อโควตากลับมา ทริกเกอร์แจ้งเตือนวันที่ 20 พฤศจิกายน 2569 คงเดิม

ดูตัวอย่างโดยไม่ส่งเมล: /email-example.html หรือเรียก previewConfirmationEmail ในตัวแก้ไข หน้าเว็บไซต์ใช้ Prompt ที่เก็บไว้ใน /public/fonts พร้อมใบอนุญาต OFL ตัวอ่านอีเมลที่ไม่รองรับ Prompt จะใช้ฟอนต์สำรอง

เมลยืนยันไม่แสดงกำหนดการและวิทยากร ส่วนข้อมูลดังกล่าวอยู่ในอีเมลเตือนเข้าร่วมโครงการเท่านั้น
