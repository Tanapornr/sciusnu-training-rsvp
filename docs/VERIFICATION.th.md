## ข้อจำกัดของผลตรวจ

- ชุดทดสอบไม่เพิ่มผู้เข้าร่วมสมมติลงทะเบียนจริง การทดสอบบน production ใช้เฉพาะชื่อที่มีอยู่แล้วเพื่อตรวจการปฏิเสธชื่อซ้ำ
- หน้าสำเร็จใหม่มีชื่อและสังกัด/คณะ ไม่มีรหัส ข้อความพิมพ์หลักฐาน หรือปุ่มลงทะเบียนให้ท่านอื่น รหัสภายในยังจำเป็นสำหรับ idempotency และเก็บใน Sheet
- การเปิดแอปปฏิทินจริงบนมือถือขึ้นกับระบบปฏิบัติการ เบราว์เซอร์ และแอปที่ติดตั้ง ยังไม่ได้ทดสอบบนโทรศัพท์จริง คอมพิวเตอร์เปิดหน้า Outlook ที่ผู้ใช้กำหนด โดยไม่สร้างนัดหมายให้อัตโนมัติ
- การทดสอบรันในเครื่องด้วย Node.js 24.14.0; โครงการระบุ Node.js 22.x และ Vercel build สำเร็จ
- CacheService จำกัดแบบ best effort 120 รายการใหม่ต่อ IP hash ต่อช่วง 10 นาที เป็นการป้องกันการส่งจำนวนมากจากเครือข่ายเดียว ไม่ใช่โควตาของสังกัด
