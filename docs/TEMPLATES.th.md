# รูปแบบเว็บไซต์

เทมเพลตที่ 1 คือรูปแบบเดิม โทนเขียวเข้ม–ครีม เก็บไว้ที่ `public/template-1/index.html` และยังใช้เป็นหน้าหลัก `public/index.html` เหมือนเดิม

เทมเพลตที่ 2 เป็นหน้ารวมตามภาพอ้างอิง โทนขาวครีม–เขียวเข้ม มีโลโก้และชื่อโครงการตัวใหญ่หนาสีดำด้านบน ตามด้วยสถานที่ แผนที่ วันเวลา และข้อความแนะนำ จากนั้นจัดกำหนดการไว้ซ้ายและแบบฟอร์มไว้ขวาบนคอมพิวเตอร์ บนมือถือเรียงต่อกันในหน้าเดียว เก็บไว้ที่ `public/template-2/index.html` และ `public/template-2/styles.css`

หลัง deploy เปิด `/template-1/` และ `/template-2/` เพื่อเปรียบเทียบ ทั้งสองแบบใช้ `/app.js`, validation, API, Google Sheets และระบบอีเมลชุดเดียวกัน ผู้เข้าร่วมจึงลงทะเบียนได้เพียงครั้งเดียวข้ามทั้งสองหน้า

แบบที่ 2 คงข้อมูลวิทยากร สถานที่ แผนที่ ช่องอีเมล ข้อความยืนยัน และปุ่มบันทึกการลงทะเบียนเป็นรูป ข้อความเตือนวันที่ 20 ใต้ช่องอีเมลและปุ่มปฏิทินถูกเอาออกตามที่กำหนด

การใช้สองเทมเพลตบนโดเมนเดียวกันไม่ต้องเพิ่ม secrets หรือ Apps Script URL ใน client และไม่ต้องเปลี่ยน environment variables
