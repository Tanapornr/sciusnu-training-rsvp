# รูปแบบเว็บไซต์

- /template-1/ เก็บเทมเพลตที่ 1 โทนเขียว–ครีมไว้ตามเดิม
- / และ /template-2/ เป็นเทมเพลตที่ 2 ตามภาพอ้างอิงโทนขาว–ส้ม ไม่มีเมนูด้านบน แสดงวิทยากรคู่กัน และแบบฟอร์มคู่ข้อมูลการจัดงาน เมื่อจอแคบจะแสดงแนวตั้ง
- ทั้งสองแบบใช้ Prompt และข้อมูลลงทะเบียนเดิม: คำนำหน้า ชื่อ-นามสกุล อีเมล สังกัด/คณะ
- ลงทะเบียนสำเร็จแล้วส่งอีเมลยืนยัน ไม่มีปุ่มบันทึกรูปหรือเพิ่มในปฏิทิน
- ภาพประกอบอาคารส่วนหัวของเทมเพลตที่ 2 แสดงจากส่วนภาพอ้างอิงที่ผู้จัดส่งมา โดยจัดกรอบด้วย CSS
- ตัวอย่างอีเมลที่ไม่บันทึกทะเบียนหรือส่งอีเมล: /email-example.html
